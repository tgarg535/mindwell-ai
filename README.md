# MindWell AI — Mental Health Screening Agent (Prototype)

A single-file, zero-dependency web prototype of the AI-powered mental health screening
agent built during the **IBM SkillsBuild Agentic AI internship (Project-Based Learning Program)**.

It replicates the report's end-to-end workflow:
**Google Form input → webhook trigger → NLP/sentiment analysis → classification
(Normal / Mild / Moderate / Severe) → personalized automated feedback email → escalation path.**

## Live Demo (GitHub Pages)
Once enabled, the app runs at:
`https://<your-username>.github.io/<repo-name>/`

## Run locally
Just open `index.html` in any browser — no server, build step, or API keys needed.

## Deploy steps (GitHub Pages)
1. Create a new repository on github.com (e.g. `mindwell-ai`).
2. Upload `index.html` (and optionally this README) to the repo root.
3. Go to **Settings → Pages → Source: Deploy from a branch → Branch: main → / (root) → Save**.
4. Wait ~1–2 minutes; visit the URL shown above.

## Disclaimer
Prototype for academic evaluation. Preliminary screening only — not a medical diagnosis.
